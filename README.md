# Computer Library

Личная библиотека книг о программировании и устройстве компьютеров. Книги распределены по языку: [русский (RU)](RU/) и [English (EN)](EN/). В каталог добавляются материалы, условия которых допускают хранение и распространение.

## Русский — RU

- [Дэниел Холден — Создаём свой Lisp](<RU/Дэниел Холден - Создаём свой Lisp.pdf>) — создание собственного интерпретатора на C. Перевод по книге *Build Your Own Lisp*.
- [Иэн Виенанд — Информатика снизу вверх](<RU/Иэн Виенанд - Информатика снизу вверх.pdf>) — архитектура, операционные системы, память, инструменты разработки и компоновка. Перевод издания 2013 года; надписи на схемах оставлены на английском.
- **Брайан Холл — Руководство по программированию на C** — сокращённый русский перевод хранится только в локальной копии библиотеки и не загружается в публичный репозиторий: автор разрешает распространение перевода при условии воспроизведения книги целиком. [Английский оригинал](<EN/Brian Hall - Beej Guide to C Programming.pdf>).

## English — EN

- [Daniel Holden — Build Your Own Lisp](<EN/Daniel Holden - Build Your Own Lisp.pdf>) — a PDF assembled from the author's freely available online edition.
- [Brian Hall — Beej’s Guide to C Programming](<EN/Brian Hall - Beej Guide to C Programming.pdf>) — the original tutorial edition.
- [Ian Wienand — Computer Science from the Bottom Up](<EN/Ian Wienand - Computer Science from the Bottom Up.pdf>) — the original 2013 edition.

- *Build Your Own Lisp*: [оригинал](https://www.buildyourownlisp.com/), текст — [CC BY-NC-SA 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/); условия кода и сведения об изображениях указаны в оригинале.
- *Beej’s Guide to C Programming*: [оригинал и условия автора](https://beej.us/guide/bgc/); точные условия перевода приведены в предисловии оригинала.
